# BMI Calculator (.NET MAUI) Beta

BETA ВЕРСИЯ, ПРЕДВАРИТЕЛЬНАЯ

Кроссплатформенное мобильное приложение для расчета индекса массы тела (ИМТ), разработанное на платформе .NET MAUI.

Проект выполнен в рамках производственной практики в Тюменском индустриальном университете и демонстрирует разработку мобильного приложения с использованием архитектуры MVVM и облачной платформы Supabase.

---

## ✨ Возможности

- Регистрация и авторизация пользователей
- Расчет индекса массы тела (ИМТ)
- Отображение результата с рекомендациями
- История расчетов
- Профиль пользователя
- Хранение данных в облачной базе Supabase

---

## 🛠️ Стек технологий

- .NET MAUI
- C#
- XAML
- CommunityToolkit.MVVM
- Supabase

---

## 📡 Архитектура

Приложение построено с использованием архитектурного паттерна MVVM.

В качестве облачной платформы используется Supabase, обеспечивающая:

- аутентификацию пользователей;
- хранение результатов расчетов;
- управление учетными записями пользователей.

Архитектура позволяет разделить пользовательский интерфейс, бизнес-логику и работу с данными.

## 🚀 Запуск

Перед запуском убедитесь, что установлен .NET SDK версии .NET 9 с поддержкой .NET MAUI.

Проверьте установленную версию:

```bash
dotnet --version
```

При необходимости установите workload:

```bash
dotnet workload install maui
```

Восстановите зависимости:

```bash
dotnet restore
```

Соберите проект:

```bash
dotnet build
```

После этого приложение можно запустить через Visual Studio или с помощью .NET CLI.
